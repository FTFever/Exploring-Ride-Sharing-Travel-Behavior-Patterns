# Project scope

Descriptive baseline, temporal and spatial analysis of NYC HVFHV trip demand, followed by 168-hour zone-level pickup prediction. Sources and geographic/time definitions are documented separately. Current modeling uses 2021–2025 training with January 1–7, 2026 final testing. Training-history-length experiments belong to a planned 07 notebook. The current results do not establish causal policy effects or a fully selected winning model.

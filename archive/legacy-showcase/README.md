# Legacy showcase assets

This folder preserves presentation assets that predate the reproducible project
structure:

- `Dashboard.html` — Tableau Public embed wrapper
- `aggragated_month_all_vehicle.png` — historical monthly licensed-vehicle figure
- `aggragated_month_categories.png` — historical monthly vehicle-category figure
- `aggragated_month_fhvhv.png` — historical monthly high-volume FHV figure

The original filenames are retained to preserve provenance, including the
`aggragated` spelling. These files are archived reference artifacts and are not
currently generated by the repository's reproducible pipelines.
